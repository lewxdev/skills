# skills

a collection of reusable [agent skills](https://agentskills.io/) for my development workflows

## available skills

| skill | purpose |
| --- | --- |
| [`github-issue`](skills/github-issue/SKILL.md) | draft and create issues that follow the target repository's templates and contribution guidelines |

## install

for codex, using the [skills cli](https://github.com/vercel-labs/skills):

```shell
npx skills add lewxdev/skills --global
```

other compatible agents can install the same skill

github access must be available through an authenticated integration or cli
